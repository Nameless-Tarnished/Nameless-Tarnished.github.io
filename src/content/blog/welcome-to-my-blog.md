欢迎来到我的个人空间。

我希望这里不只是一个冷冰冰的文章列表，而是一个**安静、有呼吸感、适合长文阅读**的个人数字花园：既能专注沉淀技术实践与代码复盘，也能顺手放一放最近在看的动画、常听的专辑和零星短记录。

::repo{repo="Nameless-Tarnished/Nameless-Tarnished.github.io"}

## 站点包含的核心功能

这套博客基于 Astro 纯静态构建，内置了以下完整功能：

- **长文阅读体验**：顶部阅读进度条、右侧粘性目录（`ON THIS PAGE`）、标题自动锚点与代码块一键复制。
- **系列连载与导航**：支持把同主题文章串联为系列，自动生成「上一章 / 下一章」与系列目录页。
- **全站检索（⌘K）**：构建期生成轻量搜索索引，按 `Ctrl/⌘ + K` 或点击右上角 Search 即可瞬时检索文章、标签与页面。
- **日夜环境光切换**：顶部支持夏日浅色与夜晚深色模式切换，随时间或偏好保持舒适阅读对比度。
- **作品、短记录与音乐页**：除常规博客与归档外，还配有作品展示区、短记录时间线与歌词同步音乐角。

## 接下来怎么使用

```bash
# 本地启动开发预览
npm run dev

# 执行中文字体子集化、类型检查与静态构建
npm run build
```
